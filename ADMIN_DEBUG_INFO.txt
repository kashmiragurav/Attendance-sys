## 💡 Common Issues

### Issue: Role is 'user' instead of 'admin'
**Solution:** The admin account was saved with wrong role
- Delete the account from Firebase Auth
- Delete from Firestore users collection
- Try login again (it will auto-create with role='admin')

### Issue: Still showing employee dashboard
**Solution:** Wait for Firestore to sync
- Sometimes Firestore takes a moment
- AuthContext should fetch updated data
- Check browser console for errors

### Issue: "Not Checked In" error
**Solution:** That's the EMPLOYEE dashboard
- You should see Admin Dashboard instead
- With employee tabs and statistics
- If not, admin account wasn't created properly
